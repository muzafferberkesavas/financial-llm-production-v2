## Deployment Sırası

### 1. Backend (Render)

1. **GitHub'a push** — `render.yaml` repo'da olsun
2. **Render.com** → New → Blueprint → repo'yu seç → `render.yaml` algılansın
3. **Secrets ekle** (Settings → Environment):
   - `ANTHROPIC_API_KEY` — claude.ai/console'dan
   - `FINNHUB_API_KEY` — finnhub.io ücretsiz
   - `TELEGRAM_BOT_TOKEN` — @BotFather'dan
   - `TELEGRAM_CHANNEL_NASDAQ` — @your_channel veya -100xxx
   - `TELEGRAM_CHANNEL_BIST` — yine
4. **Deploy** — ilk build ~5 dakika
5. **Health check**: `https://finllm-api.onrender.com/v2/health`
6. **API_BEARER_TOKEN** Render UI'dan kopyala — dashboard'a vereceksin

### Alternatif: Neon Postgres (Render Postgres yerine)

Neon ücretsiz tier 3GB. `render.yaml`'daki `databases:` bloğunu sil, env'e:

```bash
DATABASE_URL=postgresql+psycopg://user:pass@ep-xxx.eu-central-1.aws.neon.tech/finllm
```

### 2. Database init

İlk deploy sonrası tablo oluşturma:

```bash
# Render Shell veya yerel
DATABASE_URL=postgresql+psycopg://... python -c "
from finllm.storage.engine import init_schema
init_schema()
"
```

İsteğe bağlı: geçmiş JSON'ları DB'ye taşı:
```bash
python scripts/migrate_json_to_db.py
```

### 3. Dashboard (Vercel)

1. **Vercel.com** → New Project → GitHub repo
2. **Root Directory** = `dashboard`
3. **Framework** = Next.js (auto-detect)
4. **Environment Variables**:
   - `BACKEND_API_URL` = `https://finllm-api.onrender.com`
   - `API_BEARER_TOKEN` = (Render'dan kopyaladığın)
5. **Deploy** — ~2 dakika

### 4. Telegram bot kurulumu

1. **@BotFather** → `/newbot` → `FinLLM_Signals_Bot` (örnek)
2. Token al, Render env'e koy: `TELEGRAM_BOT_TOKEN=...`
3. **Kanal oluştur**: @nasdaq_signals (public veya private)
4. Bot'u kanala admin ekle (Post messages permission)
5. Kanal username veya ID: Render env: `TELEGRAM_CHANNEL_NASDAQ=@nasdaq_signals`
6. **Test**: Render Shell'de:
   ```bash
   python scripts/telegram_test_post.py --market nasdaq
   ```

### 5. İlk pipeline tetikle

Cron beklemeden manuel run:

```bash
# Render Shell
python scripts/run_funnel.py --market nasdaq --llm claude
```

veya API trigger:
```bash
curl -X POST https://finllm-api.onrender.com/v2/trigger/run \
  -H "Authorization: Bearer YOUR_BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"market":"nasdaq","mode":"pre_market","llm_backend":"claude","capital":10000}'
```

## Env Var Reference

`.env.production` örneği:

```bash
# LLM
ANTHROPIC_API_KEY=sk-ant-api03-...
FINNHUB_API_KEY=...

# Telegram
TELEGRAM_BOT_TOKEN=12345:ABC...
TELEGRAM_CHANNEL_NASDAQ=@finllm_nasdaq
TELEGRAM_CHANNEL_BIST=@finllm_bist
TELEGRAM_ADMIN_IDS=123456,789012

# Database
DATABASE_URL=postgresql+psycopg://...

# API
API_BEARER_TOKEN=<auto-generated>
PUBLIC_READ=true       # GET endpoint'lere anonim erişim
ENV=production
LOG_LEVEL=INFO

# Dashboard (Vercel)
BACKEND_API_URL=https://finllm-api.onrender.com
```

## Monitoring

- **Render logs**: Dashboard → Service → Logs
- **Telegram alerts** (Phase 3.4): cron failure'larda kanalda bildirim
- **Health endpoint**: `/v2/health` (Render auto-restart için)
- **Cost tracking**: Anthropic Console + Render Dashboard

## Rollback

Render: Service → Deploys → eski deploy "Rollback" tuşu.
Vercel: Deployments → previous → "Promote to Production".
